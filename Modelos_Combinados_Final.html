Ensamble de modelos¶

Ensamble de los modelos de clasificación utilizados para predecir la probabilidad de que un cliente realice una transacción:

  • Red neuronal multicapa (Neural Network)
  • XGBoost

Los modelos se entrenan y evalúan utilizando una partición común de los datos de entrenamiento, de manera que las predicciones de ambos modelos correspondan a las mismas observaciones y puedan combinarse posteriormente. Neural Network utiliza las 181 variables seleccionadas mediante ANOVA, mientras que XGBoost utiliza las 200 variables originales.

Posteriormente, las probabilidades producidas por los dos modelos se combinan mediante dos estrategias de ensamble:

  • Voting ponderado, mediante una combinación lineal de las probabilidades generadas por los dos modelos. Los pesos se seleccionan usando solo las predicciones out of fold del conjunto de entrenamiento. La combinación seleccionada asigna un peso de 0.46 a Neural Network y 0.54 a XGBoost.
  • Stacking, utilizando un modelo meta-aprendiz que aprende a combinar las predicciones de los modelos base a partir de predicciones OOF.

La métrica principal utilizada para comparar los modelos fue ROC-AUC, ya que la competencia evalúa la capacidad del modelo para ordenar correctamente las observaciones positivas por encima de las negativas.

Split de entrenamiento y validación¶

Para realizar una comparación justa entre los dos modelos se utiliza una única partición estratificada. El 80% de las observaciones se utilizará para entrenar los modelos y el 20% restante se reservará para validación.

La misma partición se utilizará para Neural Network y XGBoost. De esta manera, las predicciones de los dos modelos corresponden exactamente a las mismas observaciones y pueden combinarse posteriormente.

Entrenamiento de la Red Neuronal¶

La red contiene dos capas ocultas con funciones de activación ReLU, Batch Normalization y Dropout para reducir el riesgo de sobreajuste. El modelo se entrena utilizando los datos escalados y se utiliza ROC-AUC como métrica principal de seguimiento durante el entrenamiento.

def build_neural_network(input_dim):
    model = Sequential([
        tf.keras.layers.Input(shape=(input_dim,)),

        Dense(128, activation="relu"),
        BatchNormalization(),
        Dropout(0.3),

        Dense(64, activation="relu"),
        BatchNormalization(),
        Dropout(0.3),

        Dense(32, activation="relu"),
        BatchNormalization(),
        Dropout(0.2),

        Dense(1, activation="sigmoid")
    ])

    model.compile(
        optimizer=tf.keras.optimizers.Adam(
            learning_rate=0.001
        ),
        loss="binary_crossentropy",
        metrics=[
            "accuracy",
            AUC(name="auc")
        ]
    )

    return model

Para XGBoost se utilizan las 200 variables disponibles en esta versión del dataset. Esta configuración fue seleccionada previamente por el equipo como la versión utilizada para XGBoost. Se mantiene la configuración de hiperparámetros utilizada en el experimento original y se calcula scale_pos_weight utilizando únicamente las etiquetas del conjunto de entrenamiento.

    0.01,
    0.02,
    0.03,

    print(f"\nEntrenando XGBoost con learning_rate={lr}")

    model = XGBClassifier(
        n_estimators=400,
        learning_rate=lr,
        max_depth=3,
        min_child_weight=5,
        subsample=0.8,
        colsample_bytree=0.8,
        reg_alpha=0.0,
        reg_lambda=1.0,
        gamma=0.0,

        X_train_200,

N_FOLDS_STACK = 5

skf = StratifiedKFold(
    n_splits=N_FOLDS_STACK,
    shuffle=True,
    random_state=SEED
)

oof_nn = np.zeros(len(y_train))
oof_xgb = np.zeros(len(y_train))

print("Generando predicciones OOF para Stacking...")

for fold, (train_idx, fold_idx) in enumerate(
    skf.split(X_train_181, y_train), 1
):
    
    print(f"\nFold {fold}/{N_FOLDS_STACK}")
    
    # NEURAL NETWORK
    
    scaler_fold = StandardScaler()
    
    X_fold_train_nn = scaler_fold.fit_transform(
        X_train_181.iloc[train_idx]
    )
    
    X_fold_val_nn = scaler_fold.transform(
        X_train_181.iloc[fold_idx]
    )
    
    nn_fold = build_neural_network(
        X_fold_train_nn.shape[1]
    )
    
    callbacks_fold = [
        EarlyStopping(
            monitor="val_auc",
            mode="max",
            patience=4,
            restore_best_weights=True,
            verbose=0
        )
    ]
    
    nn_fold.fit(
        X_fold_train_nn,
        y_train.iloc[train_idx],
        validation_data=(
            X_fold_val_nn,
            y_train.iloc[fold_idx]
        ),
        epochs=100,
        batch_size=512,
        callbacks=callbacks_fold,
        verbose=0
    )
    
    oof_nn[fold_idx] = nn_fold.predict(
        X_fold_val_nn,
        batch_size=512,
        verbose=0
    ).ravel()
    
    # XGBOOST
    
    xgb_fold = XGBClassifier(
        n_estimators=400,
        learning_rate=best_lr,
        max_depth=3,
        min_child_weight=5,
        subsample=0.8,
        colsample_bytree=0.8,
        reg_alpha=0.0,
        reg_lambda=1.0,
        gamma=0.0,

        objective="binary:logistic",
        tree_method="hist",
        eval_metric="auc",

        scale_pos_weight=scale_pos_weight,

        random_state=SEED + fold,
        n_jobs=2
    )
    
    xgb_fold.fit(
        X_train_200.iloc[train_idx],
        y_train.iloc[train_idx],
        verbose=False
    )
    
    oof_xgb[fold_idx] = xgb_fold.predict_proba(
        X_train_200.iloc[fold_idx]
    )[:, 1]
    
    print(
        f"OOF AUC - NN: "
        f"{roc_auc_score(y_train.iloc[fold_idx], oof_nn[fold_idx]):.5f} | "
        f"XGB: "
        f"{roc_auc_score(y_train.iloc[fold_idx], oof_xgb[fold_idx]):.5f}"
    )

print("\nPredicciones OOF generadas correctamente.")
